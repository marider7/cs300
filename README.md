# cs300

1.	What was the problem you were solving in the projects for this course?
The CS 300 projects focused on developing an advising assistance program for the Computer Science department at ABCU, which would read course information from a file, store the information in an appropriate data structure, display all Computer Science courses in alphanumeric order, and allow an advisor to search for an individual course and view its title and prerequisites. In my project one, I focused on the design and analysis of the solution before writing an actual code, where I developed pseudocodes for three different data structures: a vector, a hash table, and a binary search tree. In project two, I used the results of the analysis to implement the advising assistance program in C++. My completed program could read the course file, store the course objects using selected data structure, display the course objects in alphanumeric order, and allow the user to search for individual course information.

2.	How did you approach the problem? Consider why data structures are important to understand.
I separated the design process from the implementation process. In project one, I determined how the program should work before writing the C++ code. I compared a vector, hash table, and binary search tree based on the operations required by the advising application, including loading data, searching for courses, and displaying courses in sorted order. Data structures are important because the way information is organized directly affects the efficiency of an algorithm. 

3.	How did you overcome any roadblocks you encountered while going through the activities or project?
One roadblock that I faced was translating the requirements into pseudocode that could later be converted into working C++ code. To overcome this, I had to first sit down and think through how the program would open and read the input file, separate each line into course information, create course objects, handle prerequisites, and detect improperly formatted data. another challenge that took the big part of my work was compiler errors and incorrect program behavior. I wrote the code and the application could not read  and open the file. I had to work on my code again and again until I realized the files name had spaces which made the application unable to recognize it. To overcome this challenge, I updated my CPP code and the file was able to load the file.

4.	How has your work on this project expanded your approach to designing software and developing programs?
The course projects taught me the importance of first analyzing and designing a program before implementing it. I compared the vector, hash table, and binary search tree which strengthened my understanding of algorithmic efficiency. Project one and two also demonstrated the connection between software design and implementation.
5.	How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
This course’ project improved the way I organize and document my code. The project two assignment required naming conventions, inline comments, error handling, and separating functionality into logical functions. I practiced this which made my code easier to read and troubleshoot. I also learned that maintainability begins during the design stage. Clearly defining the responsibilities of the program’s components before implementing them  made it easier to modify the program later.
